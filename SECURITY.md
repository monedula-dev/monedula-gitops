# Security Policy

## Supported versions

The latest released version receives security fixes.

## Reporting a vulnerability

Please report security vulnerabilities **privately** via GitHub Security Advisories:
open a report at
<https://github.com/monedula-dev/monedula-gitops/security/advisories/new>.

Do not open public issues for security problems. We will acknowledge your report and work with
you on a fix and coordinated disclosure.
